# Creator Portal

The React frontend, managed with Yarn, will support media uploads, draft review, finished-video downloads, source-lineage inspection, and a list of monitored YouTube videos with current statistics and refresh times.

The portal will read YouTube information through the Application API. The YouTube API key stays on the server.

No application code, package manifest, or setup, run, and test commands exist yet. These commands must be documented when the module is scaffolded.
