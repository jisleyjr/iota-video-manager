# Application API

The Kotlin application, built with Gradle, will serve the Creator Portal and manage catalog, draft, output-lineage, and YouTube monitoring workflows.

The [YouTube monitoring design](../docs/pages/api/youtube-monitoring.adoc) describes scheduled public-channel synchronization, stored video metadata and current statistics, and read endpoints.

No application code, Gradle build, or setup, run, and test commands exist yet. These commands must be documented when the module is scaffolded.
